# A股市场每日分析 Skill (A-Share Market Daily Skill)

> 本 skill 用于在 A 股交易日（早盘 / 午盘 / 收盘 / 节假日次日）对沪深主板 + 创业板 + 科创板进行**结构化、量化、可执行**的全景分析，对标卖方所晨会纪要 + 量化基金日报。
> 适配用户画像：AI 算力链 Alpha 选手，**强 BOM 穿透思维**（必查国产标的与 NVDA/AMD/AAPL/TSMC 等海外大厂的真实采购关系），坚决拒绝"国产自嗨"高估值陷阱。
> **公共规则继承**：本 Skill 继承 `投资分析中枢` 的公共 Hard Rules；若与本文件局部规则冲突，以 `投资分析中枢` 为准。
>
> **与 [美股市场每日分析](../us-market-daily/SKILL.md) 是互补关系**：海外前导信号（NVDA/TSM/AVGO/SMH）→ 第二天 A 股算力链开盘映射。

**必须立即调用本 skill 的场景**：

1. 用户问 "分析一下今天的A股市场" / "今天A股怎么样" / "A股盘中/午盘/收盘看一下"
2. 用户问 "上证 / 深证 / 创业板 / 科创 50 现在什么状态"

5. 用户问 "A 股值不值得追" / "今天该买啥 A 股"
6. 用户在美股盘后问 "明天 A 股算力链怎么走"（**反向跨市场映射**）
7. 用户上传 A 股截图但**没有具体标的列表**，要求大盘环境判断

**禁止跳过的前置动作**：
- 必须先确认 `(now_cst, market_phase, data_age)`：盘前 / 早盘 / 午休 / 午盘 / 收盘 / 休市

- **禁止直接给结论**：所有"排名"必须基于实时 peer cohort，禁用 LLM 训练记忆
- **MCP 不可用时必须立即报警**（v1.3 硬约束 #11，不得用缓存/记忆充实时数据）

## 一.A、职责边界与路由优先级（统一规则）

### 1. 全局路由优先级

> 全局优先级矩阵 P0–P4 统一定义在 [投资分析中枢 §3](../investment-router/SKILL.md)。本 Skill 仅声明在该矩阵中的角色：

| 场景 | 本 Skill 处理方式 |
|---|---|
| 问 A 股大盘/上证/深证/创业板/科创板/板块/盘中/收盘 | **主导**，输出指数/宏观/资金/主线/跨市场映射 |
| 问"昨夜美股影响今天 A 股开盘吗 / 明天 A 股算力链怎么走" | **主导**，引用美股 Skill 的海外前导信号 |
| 出现持仓截图、ETF 持仓、补仓/清仓/止损 | **让渡** `持仓分析`，仅提供 A 股大盘/板块背景 |
| 单只 A 股估值/护城河/能否买入，无持仓 | **让渡** `个股深度分析`，本 Skill 提供 BOM 审计与自嗨规则 |
| 问"某只 A 股是否真 Alpha / 国产自嗨" | **协同** `个股深度分析`，本 Skill 提供审计框架 |

### 2. 本 Skill 的接管范围

- ✅ 接管：A 股大盘、指数、成交额、北向/两融、政策、行业主线和风格切换。
- ✅ 接管：AI 算力链、半导体、光模块、PCB、存储等 A 股板块的横向强弱和 BOM 审计。
- ✅ 接管：跨市场映射中的“海外前导信号 → A 股次日/当日板块反应”。
- ❌ 不接管：用户给出自己的持仓成本、仓位、盈亏、补仓/清仓请求，必须转 `持仓分析`。
- ❌ 不接管：用户只问单个 A 股公司基本面/估值/护城河，必须转 `个股深度分析`。

### 3. 与其他 Skill 的协同方式

- 与 `美股市场每日分析`：本 Skill 引用 NVDA/TSM/AVGO/SMH/SOXX 作为海外前导信号，但 A 股操作节奏由本 Skill 判定。
- 与 `个股深度分析`：单只 A 股的估值与护城河由个股 Skill 主导，但必须套用本 Skill 的 BOM 穿透、股权 BOM、自嗨审计和 IPO 冲击波规则。
- 与 `持仓分析`：当用户给出 A 股持仓时，本 Skill 只作为市场环境模块，不直接给最终仓位动作。
- 输出时必须说明：“本轮主 Skill = A股市场每日分析；协同引用 = [如有]”。

## 二、四层分析框架

### Layer 1：时间锚 & 市场阶段（必填，禁止省略）

输出第一行**强制**包含：
```
(now_cst: YYYY-MM-DD HH:MM 北京时间, market_phase: pre-open | morning | lunch-break | afternoon | closed | holiday, data_age: 实时 / 节前最后一日 / 节后第一日)
```

**A股交易时段**：
- 集合竞价：09:15-09:25
- 早盘：09:30-11:30
- 午休：11:30-13:00（无连续行情）
- 午盘：13:00-15:00
- 收盘：15:00（科创板/创业板有 15:00-15:30 收盘集合竞价）

**特殊场景（必查中国节假日历）**：
- 春节（农历正月初一前后，约 1 月底-2 月中）
- 清明节（4/4-4/6 前后）
- 五一劳动节（5/1-5/5）
- 端午节（农历五月初五前后）
- 中秋节（农历八月十五前后）
- 国庆节（10/1-10/7）
- 元旦（1/1 前后）

> 不得仅凭记忆判断休市日，必须用 akshare `tool_trade_date_hist_sina` 或 Futu 当日数据返回状态校验。

| 主板 | **深证成指 SZ.399001** | 同上 |

| 行业 ETF | **科创 50 ETF SH.588000** | 同上 |
| 行业 ETF | 半导体 ETF / AI ETF / 光模块 ETF | 同上（按主线动态加挂） |

**必输出"指数 - 风格 - 板块"三维矩阵**：
- 主板 vs 创业板 vs 科创板 → 价值 / 成长 / 硬科技切换

- 上证 50 vs 中证 500 vs 中证 1000 → 大票 / 中票 / 小票轮动

| 维度 | 必查项 | 数据源 |

| **货币政策** | LPR / MLF / 7 天逆回购利率 / 公开市场操作净投放 | 人民银行官网 / akshare |

**输出原则**：
- LPR 调整：1Y/5Y 必须分开报，5Y LPR 联动地产链

- 两融余额：突破 1.8 万亿 = 风险偏好高位；下破 1.6 万亿 = 杠杆出清
- 政策事件：每个必给"市场预期" + "若超预期/不及预期"双向情景

## 三、v1.5 BOM 穿透 & 自嗨审计（A 股核心特色，禁止省略）

> 本节是 A 股 Skill 与 美股 Skill 的**根本差异**——A 股大量"国产替代"概念股海外采购占比 < 10% 但 PE > 100×，属于纯炒作标的。必须强制审计。

### 1. 替代性等级定义
| 等级 | 定义 | 案例 |
|---|---|---|
| **S** | 海外大厂必采、技术壁垒高、国产唯一/寡头 | 工业富联（NVDA 代工）/ 澜起科技（MRDIMM 国标）/ 寒武纪（部分） |
| **A** | 海外大厂部分采购、国产二供/三供 | 沪电股份（NVDA PCB 二供）/ 新易盛（CSP 光模块）/ 长电科技（封装） |
| **B** | 国内可替代、海外仍主导 | 兆易创新 / 韦尔股份 / 佰维存储 |
| **C** | **纯国产自嗨**：海外大厂不采购，全靠国内补贴 + 政策驱动 | 中国卫星 / 风华高科 / 蓝色光标 |

### 2. 自嗨预警三件套（任意命中即标 🚨）
- **PE_TTM > 100×** 同时
- **海外大客户营收占比 < 10%**（必查公司年报"前五大客户"披露） 同时
- **无 NVDA/AMD/AAPL/TSMC/Samsung/SK Hynix/Intel/Broadcom/Micron BOM 关系**

### 3. 输出要求
每个用户清单标的必须给出：
- 替代性等级（S/A/B/C）
- 海外 BOM 关系（具体公司 + 占比，必须有年报来源）
- 自嗨预警标记（🚨/⚠️/✅）

### 4. 上市公司间股权穿透（v1.6 新增维度，修补 v1.5 漏洞）

> v1.5 框架的盲区：仅看「**产品 BOM**」(标的卖给谁、零件谁的)，忽略「**股权 BOM**」(标的持有谁的股权 → 间接吃哪条 Alpha 链)。

**典型反例 — 中科曙光 (SH.603019)**：
- 是否持有海光信息 (SH.688041)、持股比例、持股数量、投资收益贡献，必须以最新年报/季报/公告实时核验。

## 四、IPO 冲击波分析框架（v1.6 新增模块，针对长鑫/长存等大型芯片 IPO）

> 本模块是 A 股 Skill 的**结构性事件分析专章**，专门处理"超级 IPO"对存量板块的**资金抽水 + 估值重构 + 叙事改写 + 板块分化**四层冲击。
> **触发条件**：单家 IPO 募资 > ¥300 亿，或 单家估值 > ¥1,500 亿，或 单家被定义为"行业龙头终极标的"（如长鑫存储、长江存储、华为海思拆分、商汤绝影、地平线 IPO 等）。

### 1. 触发条件与情景识别

**强制启动 IPO 冲击波分析的场景**：
- 用户问 "长鑫 / 长存 / XX IPO 对 A 股影响"
- 用户问 "XX 上市后 双创 / 芯片 / AI 板块怎么走"
- 用户问 "存量芯片股要不要清仓 / 长鑫上市前后操作"
- 标的所属板块进入 IPO 招股书披露窗口期（T-60 到 T+30）
- 单日有"重磅 IPO 过会 / 询价 / 上市"消息冲击大盘

### 2. 四层冲击穿透模型（必填全部 4 层）

#### Layer 1：资金抽水效应（最直接、最快兑现，T-30 到 T+15）

| 测算项 | 公式 | 阈值警报 |
|---|---|---|
| **募资规模** | 招股书发行股数 × 发行价 | > ¥300 亿 ⇒ 板块级冲击 |
| **冻结资金** | 募资额 × 平均超额认购倍数（200-300×） | > ¥3,000 亿 ⇒ T-3 到 T+1 全板块杀流动性 |
| **抽水强度比** | 冻结资金 / 板块日均成交 | > 100% ⇒ 板块级流动性踩踏 |
| **公募调仓压力** | TOP10 半导体基金重仓股 × 平均调仓比例 | > 5% ⇒ 边缘标的被踢概率 70%+ |

**资金腾挪路径模板**：
```
T-30 ~ T-15 (招股书披露): 高位芯片股开始派发，转移至打新账户
T-7 ~ T-1   (网下询价):   存量 DRAM/NAND 概念股放量阴跌
T 日        (上市):       新股上市当天，整个细分链普跌 5-10%
T+5 ~ T+15  (开板期):     资金回流，但只回流到龙头，伪概念股不归
```

#### Layer 2：估值体系重构（最深远、3-12 个月兑现）

> 这是核武器层面的冲击。新龙头的 PE 会成为整个细分赛道的**新锚定**。

**重锚 PE 测算公式**：
```
重锚 PE 中枢 = (新龙头发行 PE × 0.7) ~ (新龙头发行 PE × 1.2)
存量标的合理 PE = 重锚 PE × 真 Alpha 含量比例
存量标的估值压缩幅度 = 1 - (重锚 PE × 真 Alpha 比例) / 当前 PE
```

**重锚效应分级（按 IPO 标的体量）**：
| IPO 体量 | 重锚效应 | 影响范围 |
|---|---|---|
| 单家募资 > ¥500 亿 | **强重锚** | 全细分赛道 PE 中枢下移 30-60% |
| 单家募资 ¥300-500 亿 | 中重锚 | 直接竞品 PE 下移 20-40% |
| 单家募资 ¥100-300 亿 | 弱重锚 | 仅最核心 1-2 标的受影响 |
| 单家募资 < ¥100 亿 | 无重锚 | 不触发 IPO 冲击波分析 |

#### Layer 3：叙事重构（真假国产替代识别）

**Before / After 范式革命模板**：
| 维度 | IPO 前 | IPO 后 |
|---|---|---|
| 估值逻辑 | 故事就是估值 (PEG 不重要) | BOM 穿透 + 真 Alpha 识别 (PEG 重新挂帅) |
| 龙头标准 | 谁先讲故事谁是龙头 | 谁有真实出货量谁是龙头 |
| 概念股 | 沾边即涨 | 真假分化、伪概念归零 |

**真受益 vs 假受益**识别清单（强制输出）：
- ✅ S 级真 Alpha：进新龙头供应链 / 上下游配套（**利好**）
- 🚨 C 级伪概念：与新龙头同业但无技术壁垒（**利空**，定价归零）
- ⚠️ B 级中间态：有真实业务但被新龙头挤占（**估值杀伤**）

#### Layer 4：双创流动性 + 风格切换

| 维度 | 必查项 |
|---|---|
| **公募基金调仓** | TOP10 半导体基金的"踢仓概率"（按持仓权重计算被替代概率） |
| **北向资金重定价** | 外资是否会从其他高估标的（如寒武纪/海光）切换至 IPO 新龙头 |
| **风格切换** | AI 算力主线 → 存储/设备/材料主线（资金重心迁移） |
| **创业板/科创板分流** | 主板 vs 双创成交额比 / 北向资金主板 vs 双创占比 |
