# 港股IPO投资分析 Skill (HK IPO Analysis Skill)

> 本 Skill 用于对**港股新股（IPO）**做"打新决策级"分析，目标是判断**是否申购 + 中签率 + 暗盘/首日博弈策略**。
> 适配用户画像：港股打新参与者，关注首日溢价、中签率、孖展超购、暗盘表现，而非长期持有。
> **公共规则继承**：本 Skill 继承 `投资分析中枢` 的公共 Hard Rules；若与本文件局部规则冲突，以 `投资分析中枢` 为准。
>
> ⚠️ **本 Skill 最核心的纪律**：**打新首日博弈 ≠ 价值投资**。决定中签后赚不赚的是「筹码结构 + 情绪」，**不是**「DCF + 毛利率 + 护城河」。严禁用 `个股深度分析` 的价值框架去评判"该不该打新博首日"——这是本 Skill 诞生的根本原因（详见第三章教训）。

## 一、调用条件（Trigger Conditions）

**必须立即调用本 Skill 的场景**：

1. 用户问 "XX 港股 IPO 值不值得打 / 要不要打新 / 打不打"
2. 用户问 "XX 新股中签率 / 超购倍数 / 孖展 / 顶头槌"
3. 用户问 "XX 暗盘怎么样 / 首日会涨吗 / 首日溢价"
4. 用户问 "XX 招股 / 招股价 / 基石 / 绿鞋 / 回拨机制"
5. 用户对比多只正在招股的港股新股、做资金分配权衡
6. 用户复盘某只已上市新股的首日表现（如"XX 暗盘暴涨我能理解吗"）

**禁止跳过的前置动作**：
- 必须用 WebSearch 拉取**实时**招股信息：发行价、招股日期、暗盘日、上市日、每手股数、入场费、全球发售股数、公开发售占比、基石、绿鞋、回拨机制、保荐人
- 必须用 WebSearch 拉取**实时**孖展超购倍数（注明截至时点，孖展数据高频跳动）
- 必须确认时间锚：当前处于 招股期 / 暗盘日 / 上市日 / 已上市，**决策窗口还剩几天**
- ❌ 禁止用训练记忆给招股数据；❌ 禁止用价值框架代替打新框架下结论

## 二、打新首日博弈四件套框架（核心方法论）⭐

> 港股打新首日表现的驱动 = **筹码结构 × 情绪**，与基本面弱相关。
> 核心机理是 **Float Squeeze（货源归边/流通性挤压）**：未中签的踏空资金 + 暗盘投机 + 首日跟风盘，三股力量冲击稀缺的可流通浮筹 → 价格被引爆。
> 必须对每只新股的下列**四件套 + 两个护盘项**逐一打分（✅/⚠️/❌）。

### 四件套（决定首日上行弹性）

| # | 要素 | 数据来源 | 越…越易暴涨 | 量化参考 |
|---|---|---|---|---|
| ① | **流通盘 / 真实浮筹** | 全球发售股数 − 基石锁仓 − 国配锁定 | 浮筹越小越易暴涨 | 真实浮筹 < 1000万股 = 核弹级稀缺 |
| ② | **基石锁仓比例** | 配售结果 / 招股书 | 锁仓越多浮筹越少 = 助燃剂 | 锁仓 > 25% = 强稀缺放大 |
| ③ | **超购倍数 + 一手中签率** | 实时孖展 + 配售结果 | 超购越高踏空资金越多 | 超购 > 1000倍 / 中签率 < 2% = 踏空海量 |
| ④ | **题材 + 情绪载体** | 行业 + 品牌认知度 | 散户易懂 > 硬科技 | 国民品牌/网红消费 > 难懂硬科技 |

### 两个护盘项（决定首日下行风险）

| 项 | 含义 | 缺失后果 |
|---|---|---|
| **绿鞋（超额配售权）** | 承销商首日护盘工具 | 无绿鞋 = 破发无护盘，跌得更狠 |
| **基石背书** | 大机构信用 + 锁仓 | 无基石 = "裸奔式发行"，缺安全垫 |

### 打分结论映射

- **四件套全中 + 有基石绿鞋** → 首日大概率暴涨，可博暗盘（典型：溜溜梅 6/15 首日+194%）
- **中 2-3 件** → 首日有溢价但确定性中等，小注博弈
- **中 ≤ 1.5 件 或 双无（无基石无绿鞋）** → 首日弹性弱、下行尾部风险大，**严禁融资**，现金小注或放弃

## 三、核心教训：打新框架 vs 价值框架（本 Skill 立身之本）

> **背景**：分析海清智元(01392)时曾过度侧重价值面（现金流、PE 171倍、BOM卡脖子）下"谨慎"结论；而溜溜梅(06658)基本面平庸（营收增速 5.9%、毛利率连降、主业萎缩）却暗盘翻倍、首日+194%。**用价值框架评打新 = 看对公司、看错打新结果。**

| 维度 | 价值框架（个股深度分析用） | 打新首日博弈框架（本 Skill 用） |
|---|---|---|
| 核心问题 | 公司值不值得长期持有 | 中签后首日/暗盘能不能赚 |
| 关键变量 | DCF、毛利率、护城河、增速、FCF | 浮筹、基石锁仓、超购、中签率、题材情绪 |
| 基本面权重 | 决定性 | **很低**（仅影响破发后能否长持） |
| 适用时段 | 上市后中长期持有 | 暗盘 + 首日（T+0~T+1） |

**铁律**：
1. 判断"该不该打新博首日" → **只用四件套框架**，基本面退居次席。
2. 判断"中签后破发了能不能转长持" → 才切换 `个股深度分析` 价值框架。
3. 输出时若给出基本面分析，必须显式标注"此为价值视角，不主导打新首日决策"。

### 案例库（持续维护，校准锚点）

| 标的 | 代码 | 四件套 | 护盘 | 首日实际 | 教训 |
|---|---|---|---|---|---|
| 溜溜梅 | 06658 | 全中（浮筹807万/基石锁30%/6586倍·中签1.5%/国民品牌） | 有基石 | **+194%** | Float Squeeze 教科书；基本面平庸不妨碍首日暴涨 |
| 海清智元 | 01392 | 中1.5（超购✅/题材半个；浮筹8516万股不稀缺❌/无基石❌） | 双无 | 待验证 | 超购虚高 ≠ 稀缺；无基石无绿鞋两头极端 |

## 四、中签率测算方法

> ⚠️ **超购倍数 ≠ 中签率**。超购是"资金/孖展口径"，中签率由「公开发售货量 vs 参与人数」决定。

**测算步骤**：
1. **公开发售货量**：公开发售股数 ÷ 每手股数 = 总手数（这是中签率天花板）
2. **回拨机制判定**：
   - 传统 A 机制：超购 ≥ 100倍强制回拨公开发售至 50%（散户受益，货量扩容）
   - **机制 B：无强制回拨**，公开发售固定（常 10%）—— 超购再高货量也不扩容，散户结构性吃亏
3. **参与人数**：取实时孖展 + 历史同热度新股估算（注明为估算，非实配）
4. **一手中签率** ≈ 受理申请数 ÷ 有效申请数（配售结果公布后为确数）

**输出纪律**：中签率精确值以**交易所配售结果公告**为准（通常上市前 1-2 交易日公布）；公告前给情景区间 + 显式标注"估算"，禁止编死数字。

## 五、操作纪律（if-then 模板）

```
现金一手党:
  → 四件套中 ≥ 3 件: 可小注博暗盘（当彩票，中签率低则不强求）
  → 四件套中 ≤ 1.5 件 / 双无: 现金小注或放弃，下调首日预期
  → 中签后: 暗盘/首日冲高离场，不恋战（打新票≠长线标的）

大资金 / 顶头槌:
  → 仅在"有基石锁仓 + 浮筹稀缺 + 超购高"三者齐备时考虑
  → 双无标的不推荐顶头槌（融资利息确定 vs 中签/涨幅不确定）

红线:
  → ❌ 严禁孖展融资打"双无（无基石无绿鞋）"新股，破发即放大亏损
  → ❌ 超购越热，首日获利盘砸盘风险越大，勿在暗盘/首日高位接盘
  → ❌ 别用上一只暴涨新股（如溜溜梅）的涨幅锚定下一只，逐只独立打分
```

## 七、本地附加硬约束（继承中枢 Hard Rules §2）

1. **实时数据强制**：招股信息、孖展超购倍数必须当次 WebSearch 现拉，注明截至时点。
2. **超购 ≠ 中签率**：禁止把超购倍数直接当中签率（如"4000倍=1/4000"是错误）。
3. **机制 B 警示**：识别"无强制回拨"机制时必须显式提示散户结构性吃亏（货量锁死）。
4. **双无警示**：无基石 / 无绿鞋必须显式标注"破发无护盘 + 缺安全垫"。
5. **框架不串用**：打新首日决策只用四件套；价值分析须标注"不主导打新决策"。
6. **不锚定前票**：禁止用前一只新股涨幅推断本只，逐只独立打分。
7. **不 FOMO + 严禁融资双无票**：超购越热越警惕首日砸盘；双无标的禁孖展。
8. **配售结果为准**：中签率精确值以交易所配售公告为准，公告前标"估算"。
