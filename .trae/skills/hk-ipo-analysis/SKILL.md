# 港股IPO投资分析 Skill (HK IPO Analysis Skill)

> 本 Skill 用于对**港股新股（IPO）**做"打新决策级"分析，目标是判断**是否申购 + 中签率 + 暗盘/首日博弈策略**。
> 适配用户画像：港股打新参与者，关注首日溢价、中签率、孖展超购、暗盘表现，而非长期持有。
> **公共规则继承**：本 Skill 继承 `投资分析中枢` 的公共 Hard Rules；若与本文件局部规则冲突，以 `投资分析中枢` 为准。
>
> ⚠️ **本 Skill 最核心的纪律**：**打新首日博弈 ≠ 价值投资**。决定中签后赚不赚的是「筹码结构 + 情绪」，**不是**「DCF + 毛利率 + 护城河」。严禁用 `个股深度分析` 的价值框架去评判"该不该打新博首日"——这是本 Skill 诞生的根本原因（详见第三章教训）。

## 二、打新首日博弈框架（核心方法论）⭐

> 港股打新首日表现的驱动 = **筹码结构 × 情绪**，与基本面弱相关。
> 核心机理是 **Float Squeeze（货源归边/流通性挤压）**：未中签的踏空资金 + 暗盘投机 + 首日跟风盘，三股力量冲击稀缺的可流通浮筹 → 价格被引爆。
> v1.2 修正：申购前用**六维打分卡**判断是否打新；配售结果/暗盘出来后，用**暗盘强度过滤器**决定是否暗盘卖、首日是否继续拿。

### 2.1 四件套（决定首日上行弹性）

| # | 要素 | 数据来源 | 越…越易暴涨 | 量化参考 |
|---|---|---|---|---|
| ① | **流通盘 / 真实浮筹** | 全球发售股数 − 基石锁仓 − 国配锁定 | 浮筹越小越易暴涨 | 真实浮筹 < 1000万股 = 核弹级稀缺 |
| ② | **基石锁仓比例** | 配售结果 / 招股书 | 锁仓越多浮筹越少 = 助燃剂 | 锁仓 > 25% = 强稀缺放大 |
| ③ | **超购倍数 + 一手中签率** | 实时孖展 + 配售结果 | 超购越高踏空资金越多 | 超购 > 1000倍 / 中签率 < 2% = 踏空海量 |
| ④ | **题材 + 情绪载体** | 行业 + 品牌认知度 | 稀缺、首发、易传播题材更易暴涨 | 18A/18C、AI、机器人、A+H硬科技、第一股/唯一股 |

### 2.2 两个护盘项（决定首日下行风险）

| 项 | 含义 | 缺失后果 |
|---|---|---|
| **绿鞋（超额配售权）** | 承销商首日护盘工具 | 无绿鞋 = 破发时缺少护盘工具；但小盘稀缺题材可被情绪覆盖 |
| **基石背书** | 大机构信用 + 锁仓 | 产业基石最强；纯财务基石次之；无基石不是一票否决，需结合发行体量和题材 |

### 2.3 v1.2 六维打分卡（申购前主模型，20 分制）

> v1.2 由 2026-06 下旬样本校准：中科闻歌、芯碁微装、麦科医药-B、真健康医疗-B、白鸽在线、来福谐波。
> 关键修正：**国际配售低、无基石、无绿鞋均不是绝对一票否决**；它们在“大盘 + 上限定价 + 题材不稀缺”时是风险，在“小盘 + 稀缺题材 + 下限定价”时可能被 Float Squeeze 覆盖。

| 维度 | 满分 | 计分规则 | 含义 |
|---|---:|---|---|
| ① **发行体量** | 4 | <5亿港元=4；5-10亿=3；10-20亿=2；>20亿=1 | 小盘更容易被少量买盘推高 |
| ② **稀缺题材** | 4 | 18A/18C、第一股、唯一股、A+H硬科技、AI/机器人等=4；细分龙头=3；常规行业=2；红海题材=0 | 题材越稀缺，踏空资金越愿意高位追 |
| ③ **定价方式** | 3 | 下限=3；中位=2；上限=0 | 下限定价代表发行人让利；上限定价压缩首日赔率 |
| ④ **国际配售 × 体量修正** | 3 | 大盘/中盘且国际<10倍=0；小盘<10亿且题材稀缺=3；国际≥15倍=3 | 国际冷淡只在大盘票中危险；小盘票可被散户情绪接管 |
| ⑤ **基石质量** | 3 | 产业基石≥30%=3；财务/国资基石≥30%=2；<10%=0 | 产业基石 > 国资/财务基石；只看占比不够，必须看业务绑定 |
| ⑥ **超购踏空热度** | 3 | 一手中签<1%=3；1%-3%=2；3%-10%=1；>10%=0 | 中签率比超购倍数更接近真实踏空强度 |

**申购前结论映射**：
- **≥17 分**：可作为主力打新标的；允许顶头槌/乙组，但仍需看资金成本。
- **15-16 分**：正常打；适合现金一手或适度加注。
- **12-14 分**：小注博弈；只适合现金参与，不建议融资。
- **<12 分**：放弃或极小注；若同时上限定价 + 大盘 + 国际<10倍，原则上弃打。

### 2.4 暗盘强度过滤器（中签后 / 上市前最后校验）

> 暗盘涨跌幅不是申购前变量，不能用于决定“当初该不该申购”；但它是中签后决定“暗盘卖 / 首日卖 / 首日继续拿”的最高优先级信号之一。

| 暗盘收盘表现 | 判定 | 操作纪律 |
|---|---|---|
| **≥150%** | 极强 Float Squeeze | 可保留少量到首日开盘，但首日冲高必须分批落袋；严禁首日高位追买 |
| **75%-150%** | 强承接 | 可暗盘卖一半、首日看开盘承接；若首日低开或快速跌破暗盘收盘价，立即走 |
| **30%-75%** | 中等承接 | 暗盘优先落袋；首日只看开盘 15-30 分钟，不恋战 |
| **0%-30%** | 弱承接 | 对高超购票尤其危险；暗盘能走就走，首日不继续赌 |
| **<0%** | 破发预警 | 原则上暗盘止损或上市日集合/开盘退出 |

**暗盘-首日背离规则**：
1. **高超购 + 暗盘弱（<30%）**：说明公开认购热度没有转化为二级承接，首日获利盘砸盘概率高。来福谐波为典型反例。
2. **低/中等超购 + 暗盘极强（≥150%）**：说明真实约束是浮筹稀缺和题材情绪，不是超购倍数。白鸽在线、真健康医疗-B为典型反例。
3. **暗盘高开后大幅回落**：看收盘价，不看盘中最高价；收盘明显低于盘中高位，首日开盘需优先落袋。

## 三、核心教训：打新框架 vs 价值框架（本 Skill 立身之本）

> **背景**：分析海清智元(01392)时曾过度侧重价值面（现金流、PE 171倍、BOM卡脖子）下"谨慎"结论；而溜溜梅(06658)基本面平庸（营收增速 5.9%、毛利率连降、主业萎缩）却暗盘翻倍、首日+194%。**用价值框架评打新 = 看对公司、看错打新结果。**

| 维度 | 价值框架（个股深度分析用） | 打新首日博弈框架（本 Skill 用） |
|---|---|---|
| 核心问题 | 公司值不值得长期持有 | 中签后首日/暗盘能不能赚 |
| 关键变量 | DCF、毛利率、护城河、增速、FCF | 浮筹、基石锁仓、超购、中签率、题材情绪 |
| 基本面权重 | 决定性 | **很低**（仅影响破发后能否长持） |
| 适用时段 | 上市后中长期持有 | 暗盘 + 首日（T+0~T+1） |

**铁律**：
1. 判断"该不该打新博首日" → **只用四件套框架**，基本面退居次席。
2. 判断"中签后破发了能不能转长持" → 才切换 `个股深度分析` 价值框架。
3. 输出时若给出基本面分析，必须显式标注"此为价值视角，不主导打新首日决策"。

## 四、中签率测算方法

> ⚠️ **超购倍数 ≠ 中签率**。超购是"资金/孖展口径"，中签率由「公开发售货量 vs 参与人数」决定。

**测算步骤**：
1. **公开发售货量**：公开发售股数 ÷ 每手股数 = 总手数（这是中签率天花板）
2. **回拨机制判定**：
   - 传统 A 机制：超购 ≥ 100倍强制回拨公开发售至 50%（散户受益，货量扩容）
   - **机制 B：无强制回拨**，公开发售固定（常 10%）—— 超购再高货量也不扩容，散户结构性吃亏
3. **参与人数**：取实时孖展 + 历史同热度新股估算（注明为估算，非实配）
4. **一手中签率** ≈ 受理申请数 ÷ 有效申请数（配售结果公布后为确数）

**输出纪律**：中签率精确值以**交易所配售结果公告**为准（通常上市前 1-2 交易日公布）；公告前给情景区间 + 显式标注"估算"，禁止编死数字。

## 五、操作纪律（if-then 模板）

```
现金一手党:
  → v1.2 打分 ≥ 15: 可正常参与；≥17 可作为主力打新标的
  → v1.2 打分 12-14: 现金小注，不用融资
  → v1.2 打分 < 12: 放弃或极小注
  → 中签后: 先看暗盘强度过滤器；暗盘/首日冲高离场，不恋战（打新票≠长线标的）

大资金 / 顶头槌:
  → 仅在 v1.2 打分 ≥ 17 且资金成本可控时考虑
  → 若 v1.2 打分 < 15，即使公开超购很高，也不做顶头槌
  → 双无标的不是绝对禁区，但必须同时满足：发行体量<5亿 + 稀缺题材 + 下限/合理定价

红线:
  → ❌ 严禁只因公开超购倍数高就融资；必须先过 v1.2 打分卡
  → ❌ 上限定价 + 中大盘 + 国际配售<10倍 + 暗盘<30%，首日不赌

  → ❌ 别用上一只暴涨新股（如溜溜梅）的涨幅锚定下一只，逐只独立打分
```

## 七、本地附加硬约束（继承中枢 Hard Rules §2）

1. **实时数据强制**：招股信息、孖展超购倍数必须当次 WebSearch 现拉，注明截至时点。
2. **超购 ≠ 中签率**：禁止把超购倍数直接当中签率（如"4000倍=1/4000"是错误）。
3. **机制 B 警示**：识别"无强制回拨"机制时必须显式提示散户结构性吃亏（货量锁死），但同时检查小盘稀缺题材是否可覆盖该劣势。
4. **双无警示 v1.2**：无基石 / 无绿鞋不是一票否决；只有在非小盘、非稀缺题材、上限定价或暗盘弱时，才升级为高风险。
5. **框架不串用**：打新首日决策用 v1.2 六维打分卡 + 暗盘强度过滤器；价值分析须标注"不主导打新决策"。
6. **不锚定前票**：禁止用前一只新股涨幅推断本只，逐只独立打分。
7. **不 FOMO + 融资纪律**：超购越热越警惕首日砸盘；v1.2 打分 < 15 不做融资；暗盘 < 30% 不赌首日继续拉升。
8. **配售结果为准**：中签率精确值以交易所配售公告为准，公告前标"估算"。
9. **暗盘信号优先级**：暗盘日之后，暗盘收盘涨跌幅、盘中回撤和成交额优先于申购前叙事；若暗盘与超购热度背离，按暗盘修正首日操作。
